Every change below is native Wix, free, and reversible. Where Wix offers a 301 redirect after a slug change, always accept it.

## 1. Rename the four slugs

Editor → Pages menu → hover each page → ⋯ → SEO basics → edit the URL slug:

| Page | Current slug | New slug |
|---|---|---|
| Dermatology & Non-Invasive | /blank-4 | /dermatology-non-invasive |
| Plastic Surgery | /blank-2 | /plastic-surgery |
| Wellness | /blank-3 | /wellness |
| Contact Us | /blank-1 | /contact |

Accept the 301 redirect prompt each time.
